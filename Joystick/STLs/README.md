This is a merge between the original Joystick files (mostly annotated with `[B21]`), edits by Reddit user ADDicT10N (mostly annotated with `[ADD]`), and my own additions / replacements (annotated with `[c0]`).
(Some files have both `[B21]` and `[ADD]`, I don't know what's up with them.)

Not all files are needed, some are duplicates, some are replaced by my own versions.
Below is a non-comprehensive list of what everything that I didn't just "print once":

# Notes
## Body
- Brake Lever was replaced by own version made for use without hall sensor
## Buttons
- Most were replaced by own versions, due to the buttons not fitting on my physical buttons
## Gimbal
- Case and new Mainframe don't fit together, check before printing
- Case Back was replaced by version with mounting holes for a 40x60mm PCB for the main controller
- X-Y Connector V2 is required twice
## Head
### Tops
- None of this was printed, replaced by my own solid version
- PCB Holder was not printed
## Z-Axis
- Only the connector screw was printed, at 105% X/Y-scale to make it fit, everything else was replaced by custom version

# Custom replacements
- Brakelever_Solid replaces the original brakelever, made for use with a limit switch and a 3mm axle
- Case_Back_With_Mounting_Holes replaces original Case Back, to mount a PCB inside the base
- Top_Solid replaces the entire Tops folder, for a top without a logo
## Button Holders
- Additional models, to hold buttons/5-way-switches/other stuff in place without PCBs
## Buttons
- Replacement buttons with larger/different holes on the back
## Z-Axis
- Replacement Z-Axis parts, without Z-Axis functionality, but option to swap in another connector
